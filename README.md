# 🌐 Personal Portfolio

A modern, responsive personal portfolio built with React and Vite to showcase my skills, projects, certifications, education, and experience in Artificial Intelligence, Data Science, and Full Stack Development.

## ✨ Features

- Modern Glassmorphism UI
- Fully Responsive
- Dark Theme
- Smooth Animations
- Interactive Navigation
- Typing Effect
- Project Showcase
- Resume Download
- Contact Section

## 🛠️ Tech Stack

- React
- Vite
- JavaScript
- Tailwind CSS
- Framer Motion

npm install
npm run dev
